# 기능 구현 상세 명세

## 1. 입력 규칙

-   필드명: `text`
-   타입: 문자열
-   trim 후 빈 문자열이면 거절
-   최대 길이: 2,000자 (서버 기준)
-   브라우저의 글자 수 표시는 사용 편의를 위한 것이며 보안 검증을
    대체하지 않는다.
-   HTML 태그처럼 보이는 입력도 일반 텍스트로 취급한다.

## 2. 분석 결과 모델

API 성공 응답은 다음 구조를 따른다.

``` json
{
  "ok": true,
  "result": {
    "sentiment": "positive",
    "label": "긍정",
    "confidence": 87,
    "reason": "감사와 만족을 나타내는 표현이 반복되어 긍정으로 분류했습니다."
  }
}
```

허용 값: - `sentiment`: `positive | negative | neutral` - `label`:
`긍정 | 부정 | 중립` - `confidence`: 0\~100 정수 - `reason`: 한국어
1\~3문장, 최대 500자

서버는 AI 결과를 그대로 신뢰하지 말고 값과 길이를 검증한다. 허용되지
않는 라벨, 누락 필드, 범위를 벗어난 점수는 오류 처리한다.

## 3. OpenAI 프롬프트 동작

-   시스템 지시에는 감성 분류 작업과 JSON 출력 스키마만 정의한다.
-   사용자 입력은 분석할 인용 텍스트로 분리한다.
-   사용자 입력 안에 포함된 "이전 지시를 무시하라" 등의 문구를 명령으로
    따르지 않는다.
-   출력은 정해진 구조만 허용한다.
-   모델이 제공하는 confidence는 모델의 자기평가 점수임을 제품 화면과
    문서에서 명확히 한다.
-   모델명은 `OPENAI_MODEL` 환경변수로 지정하며, 에이전트가 임의로
    오래된/존재하지 않는 모델명을 하드코딩하지 않는다. 구현 시 OpenAI
    공식 문서에서 현재 지원되는 모델과 구조화 출력 방식을 확인한다.

## 4. 프런트엔드 상태

최소 상태: - `idle`: 아직 요청하지 않음 - `loading`: 요청 중 -
`success`: 정상 결과 - `error`: 실패

동작: - 입력이 바뀌면 이전 결과를 숨기거나 "새 문장을 입력했습니다"
상태로 초기화한다. - 로딩 중 중복 제출을 막는다. - 성공 시 라벨, 점수,
이유를 렌더링한다. - 오류 시 사용자용 메시지와 재시도 버튼 또는 분석
버튼을 제공한다. - DOM 삽입은 `textContent`를 사용한다.

## 5. 저장 동작

-   체크박스 `saveConsent` 기본값 false.
-   false면 Supabase 호출을 하지 않는다.
-   true면 서버가 성공 분석 결과를 저장한다.
-   저장 실패는 분석 실패로 처리하지 않는다. 결과는 보여주고 "기록
    저장은 완료되지 않았습니다"를 별도로 표시한다.
-   저장 요청에 원문 텍스트가 포함되므로 저장 동의가 명시된 경우에만
    저장한다.

## 6. 오류 코드와 사용자 문구

  -----------------------------------------------------------------------
  코드                    상황                    사용자 메시지
  ----------------------- ----------------------- -----------------------
  `VALIDATION_ERROR`      빈 값/길이 초과         입력 내용을 확인해
                                                  주세요.

  `RATE_LIMITED`          요청 제한               잠시 후 다시 시도해
                                                  주세요.

  `AI_UNAVAILABLE`        AI 서비스 오류/타임아웃 분석을 완료하지
                                                  못했어요. 잠시 후 다시
                                                  시도해 주세요.

  `INVALID_AI_RESPONSE`   AI 응답 형식 오류       결과를 안전하게
                                                  처리하지 못했어요. 다시
                                                  시도해 주세요.

  `SAVE_FAILED`           DB 저장 실패            분석은 완료됐지만 기록
                                                  저장은 실패했어요.

  `INTERNAL_ERROR`        기타 서버 오류          일시적인 문제가
                                                  발생했어요. 잠시 후
                                                  다시 시도해 주세요.
  -----------------------------------------------------------------------

내부 로그에는 요청 식별자와 오류 종류만 남기고 입력 원문, API 키, 인증
헤더를 기본적으로 기록하지 않는다.

## 7. 완료 및 검증 기준

-   긍정 예문, 부정 예문, 중립 예문 각각에 대해 결과 구조가 정상
    표시된다.
-   한국어·영어 문장 모두 요청 가능하다.
-   빈 입력과 2,001자 입력은 API 호출 없이 차단된다.
-   AI가 잘못된 JSON 또는 범위 밖 점수를 반환하는 상황을 모의해 안전하게
    실패한다.
-   저장 동의 off일 때 DB insert가 발생하지 않는다.
-   저장 동의 on일 때만 저장 시도한다.
